# ร้านเปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ Landing Page สไตล์คาเฟ่สำหรับร้าน **"เปรม นมสด"** แวะพักเติมความสดชื่นยามค่ำคืนกับนมสดแท้ 100% ขนมปังปิ้งเตาถ่าน และของทานเล่นแสนอร่อย

## 📋 ข้อมูลร้าน
- **เวลาเปิด-ปิด:** ทุกวัน 17:00 - 22:00 น.
- **เมนูซิกเนเจอร์:** นมสดแท้ 100%, นมชมพูเย็น, ปังปิ้งเนย-ช็อกโกแลต, ปังปิ้งไมโลภูเขาไฟ, ปังเย็นภูเขาไฟ
- **ราคาเริ่มต้น:** นมสด 20.- | ปังปิ้ง 12.- | อิตาเลียนโซดา 25.-

## 🛠️ เทคโนโลยีที่ใช้
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (via CDN)**
- **Font Awesome 6** (Icons)
- **Google Fonts:** Prompt
- **Responsive Web Design:** รองรับทั้งหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์ 100%

## 📂 โครงสร้างโฟลเดอร์
```
ร้านนม/
├── index.html          # หน้า Landing Page หลัก
├── logo.png            # โลโก้ร้าน
├── README.md           # รายละเอียดโปรเจกต์
├── บรรยากาศในร้าน/      # รูปภาพบรรยากาศร้านยามค่ำคืน
└── เมนูร้าน/            # รูปภาพเมนูและของทานเล่น
```

## 🚀 วิธีเปิดใช้งาน
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ได้ทันที
